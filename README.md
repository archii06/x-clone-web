# x-clone-web

A front-end clone of the X (formerly Twitter) website, built as a hands-on practice project while learning Git and GitHub.

## About the Project

This project recreates the look and feel of X's web interface. The main goal was not to build a production-ready social network, but to practice real-world Git workflows: initializing a repository, making meaningful commits, working with branches, connecting to GitHub over SSH, and pushing code to a remote repository.

## Why I Built This

I created this website during my Git tutorial. Instead of practicing on empty files, I wanted a real project to commit, branch, and push. Cloning a familiar interface like X gave me plenty of layout and styling work to version-control along the way.

## Features

- Responsive layout inspired by the X web interface
- Left sidebar navigation (Home, Explore, Notifications, Messages, Profile)
- Central feed area with post/tweet cards
- Right sidebar with search and trending sections
- Clean, modular structure that is easy to extend

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Edge, Firefox, Safari)
- [Git](https://git-scm.com/) installed on your machine

### Installation

1. Clone the repository:

   ```bash
   git clone git@github.com:your-username/x-clone-web.git
   ```

2. Move into the project folder:

   ```bash
   cd x-clone-web
   ```

3. Open `index.html` in your browser, or use a local server such as the VS Code **Live Server** extension.
